# 01_basics: 銀行口座（Account）

## 🎯 この章で学ぶこと
- **クラスとインスタンス**の作成
- **カプセル化（Encapsulation）**: 不正な値の書き換えを防ぐ状態の隠蔽
- **ゲッター / セッター**（またはプロパティ）の使い方

---

## 📋 仕様要件

`BankAccount` クラス（または `Account` クラス）を作成してください。

### 1. プロパティ（状態）
- **名義人 (`owner`)**: 文字列（作成時に指定、変更不可）
- **残高 (`balance`)**: 数値（初期値指定可、デフォルト `0`。**外部から直接変更不可**）

### 2. メソッド（振る舞い）
- **`deposit(amount)` (預金)**
  - `amount` が `0` 以下の場合はエラーを返すか失敗させ、残高を変更しない。
  - 正の数の場合、残高に加算する。
- **`withdraw(amount)` (引き出し)**
  - `amount` が `0` 以下の場合は失敗。
  - `amount` が現在の `balance` を超える場合（残高不足）は失敗。
  - 条件を満たせば残高から減算する。
- **`get_balance()` / `balance` (残高確認)**
  - 現在の残高を取得する。

---

## 🔍 言語ごとの注目ポイント

### 🐍 Python (`account.py`)
- プライベート変数には慣習的に `_balance` や `__balance` を使用する。
- ゲッター/セッターをスマートに扱う `@property` デコレータを試してみる。

### 📘 TypeScript (`account.ts`)
- `private` や `readonly` キーワードを使ってコンパイルレベルでアクセス制限をかける。
- TSの `get balance()` 構文（ゲッター）を試してみる。
